## شروع در چت

فایل **[HEFDAH-LINKEDIN-CHAT.md](HEFDAH-LINKEDIN-CHAT.md)** را در Claude یا ChatGPT بارگذاری کن و بگو:

> با هفده لینکدین شروع کن. می‌خواهم از تجربه‌های کاری‌ام برای مخاطب فارسی محتوا بسازم؛ اول کمک کن یک پست قابل استفاده بنویسم.

اگر نسخه آنلاین مخزن را در اختیار دستیار گذاشتی، از او بخواه [START-HERE.md](START-HERE.md) و منابع مرتبط را بخواند. دسترسی به لینک تضمین‌شده نیست. بارگذاری فایل یا دادن لینک به معنی نصب دائمی یا دسترسی به حساب نیست.

## چه کاری می‌کند؟

| قابلیت | مثال |
|---|---|
| پست و ۲۱ ساختار هوک | «این تصمیم پروژه را به یک پست تبدیل کن.» |
| پروفایل | «معرفی‌ام را برای جذب پروژه روشن‌تر کن.» |
| برنامه هفته | «دو ساعت وقت دارم و فقط یک تجربه تازه؛ برنامه بده.» |
| ویرایش | «طبیعی‌ترش کن؛ رسمی بودن و معنی‌اش حفظ شود.» |
| کامنت | «برای این پست دو نظر مشخص پیشنهاد بده.» |
| پاسخ | «سؤال‌ها و نقدها را جدا کن و پاسخ پیشنهادی بده.» |
| پست سندی | «این فرایند را به متن اسلایدهای فارسی تبدیل کن.» |
| بازاستفاده | «از این مقاله سه زاویه مستقل بیرون بکش.» |
| پیام | «یک معرفی کوتاه و صادقانه برای ارتباط بنویس.» |
| مرتب‌سازی پیام‌ها | «کدام پیام‌ها به پاسخ نیاز دارند؟» |
| تحلیل عملکرد | «با این آمار چه چیزی را هفته بعد امتحان کنم؟» |

## فرق نسخه فارسی

نیم‌فاصله و متن دوزبانه حفظ می‌شود؛ لحن رسمی به‌اجبار محاوره‌ای نمی‌شود. داستان، عدد و مشتری خیالی ساخته نمی‌شود. هفته کاری و مخاطب ایرانی از تقویم غربی کپی نمی‌شود. امتیاز پروفایل صرفاً روبریک تحریری است و بخش‌های دیده‌نشده صفر نمی‌گیرند. برای صفحه شرکت بررسی جدا انجام می‌شود.

این نسخه اسکریپت‌های انگلیسی پاکسازی و تشخیص متن را منتقل نکرده؛ ویرایش توسط مدل میزبان انجام می‌شود، بدون نمره انسان بودن یا وعده وایرال شدن. برای نوشتن ثبت‌نام جداگانه، API key و Python لازم نیست؛ استفاده از مدل تابع حساب و شرایط میزبان است. تحلیل آمار در صورت نیاز از ابزار محاسبه همان میزبان استفاده می‌کند.

## نصب اختیاری

[راهنمای نصب](docs/install.md): یک ورودی با ۱۱ قابلیت، یا ۱۱ میان‌بر مستقل. هر دو را هم‌زمان نصب نکن تا انتخاب اسکیل‌ها شلوغ نشود. در چت عادی نیازی به نصب نیست.

هیچ چیزی پست، ارسال، فالو یا زمان‌بندی نمی‌شود. خروجی سندی به‌صورت متن است؛ ساخت PDF به امکانات میزبان و درخواست تو بستگی دارد. آزمون‌های انسانی پیشنهادی در [سناریوهای پذیرش](docs/acceptance.md) آمده‌اند؛ کیفیت برای همه مدل‌ها تضمین نشده است.

## سازنده

[هفده / 17 Studio](https://17studio.ir) — طراحی سایت، سیستم‌های کسب‌وکار، CRM و اتوماسیون. استفاده از ابزار به سفارش پروژه یا معرفی هفده مشروط نیست. تبلیغ سازنده وارد محتوای شما نمی‌شود مگر بخواهید.

داده‌ها به سایت هفده ارسال نمی‌شوند. متن بارگذاری‌شده تابع حریم خصوصی میزبان انتخابی شماست؛ اطلاعات محرمانه را پیش از استفاده حذف کنید.
