# منشأ و تفاوت‌های نسخه فارسی

- منبع: https://github.com/Jakeschincariol/linkedin-agent-skill
- نسخه بررسی‌شده: `add2c23882fe79180737d242ff80a5da205eda6a`
- تاریخ اقتباس: 2026-10-22
- مجوز: MIT؛ متن مجوز منبع حفظ شده است.

ساختار ۱۱ قابلیت، سه شروع برای پست، ۲۱ نوع هوک، ۱۲ محور پروفایل، دسته‌بندی کامنت/پیام و ایده تحلیل داده حساب از منبع اقتباس شده‌اند. متن دستورها، مثال‌ها و معیارها برای فارسی بازنویسی شده‌اند؛ این بسته ترجمه خط‌به‌خط یا تأییدشده توسط سازنده منبع نیست.

| منبع | نسخه هفده |
|---|---|
| li-post + hooks.json | post + hooks.fa.json؛ ۲۱ ساختار با مثال‌های فارسی و فرضی مشخص |
| li-profile + rubric.json | profile + profile.fa.json؛ نامشخص≠صفر، شخص و شرکت جدا، حذف شرط سایت و چهره |
| li-plan | برنامه متناسب با زمان، تقویم و مخاطب، بدون ساعت طلایی قطعی |
| li-human و دو اسکریپت | ویرایش مبتنی بر لحن؛ اسکریپت‌های انگلیسی و detector منتقل نشده‌اند |
| li-comment و li-reply | همان کارکرد با داده واقعی، بدون جعل تجربه و اولویت‌دادن بر اساس منزلت |
| li-carousel | متن سندی RTL؛ PDF فقط در صورت ساخت و بررسی واقعی |
| li-repurpose | زاویه‌های مستقل با حفظ صاحب تجربه و ارجاع منبع |
| li-dm | پیام کوتاه؛ حد حساب و شمارش واقعی، بدون سقف روزانه ایمن ساختگی |
| li-inbox | دسته‌بندی با شاهد؛ نشانه‌های ضعیف اثبات اسپم نیستند |
| li-audit | فرمول صریح و داده گمشده، نسبت نمایش≠دسترسی یکتا، پرهیز از علت‌سازی |

حذف‌های عمدی: ادعای واترمارک بودن نویسه‌های نامرئی، پاکسازی نیم‌فاصله، امتیاز انسان بودن، سلسله‌مراتب قطعی سیگنال‌های الگوریتم، جریمه قطعی لینک خارجی، سقف عمومی دعوت روزانه و برنامه انتشار آمریکایی. ادعاهای متغیر پلتفرم را به عنوان قانون در محصول تکرار نکرده‌ایم.

بسته شامل Python کاربردی، اتصال حساب، انتشار خودکار یا جمع‌آوری داده نیست. راه‌اندازی چت و نصب اسکیل دو مسیر متفاوت‌اند. مخزن اقتباس: https://github.com/hooshmolee/hefdah-linkedin ؛ رابطه fork با منبع در GitHub حفظ شده است.
