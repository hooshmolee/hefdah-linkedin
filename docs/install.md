# نصب اختیاری

این مخزن دو روش دارد؛ فقط یکی را انتخاب کنید. نصب باید با درخواست کاربر انجام شود.

## یک ورودی با همه قابلیت‌ها — پیشنهاد اصلی

پوشه `skills/hefdah-linkedin` را با تمام فایل‌های داخلش کپی کنید:

- Claude Code: در `.claude/skills/hefdah-linkedin` پروژه، یا پوشه skills کاربرِ همان محیط.
- Codex: در پوشه skills زیر CODEX_HOME همان محیط، با نام `hefdah-linkedin`.

بعد از بازخوانی اسکیل‌ها در میزبان، با نام hefdah-linkedin یا درخواست فارسی استفاده کنید. نحوه شناسایی/فرمان‌ها به نسخه میزبان بستگی دارد؛ اگر دیده نشد از فایل چت استفاده کنید. این بسته نصب‌کننده خودکار ندارد و تنظیمات موجود را بازنویسی نمی‌کند.

## میان‌برهای مستقل

به جای ورودی اصلی، پوشه‌های `skills/hefdah-li-*` را کپی کنید. هر کدام منابع لازم خودش را دارد و به مسیر پوشه همسایه وابسته نیست. نام‌ها post، profile، plan، human، comment، reply، carousel، repurpose، dm، inbox، audit هستند.

## چت عادی

فایل `HEFDAH-LINKEDIN-CHAT.md` را بارگذاری یا متنش را کپی کنید و بگویید «با هفده لینکدین شروع کن». این فایل خودبسنده است؛ منابع داخل خودش آمده‌اند. لینک تنها ممکن است قابل خواندن نباشد و نصب دائمی ایجاد نمی‌کند.

هیچ کلید API، افزونه انتشار یا دسترسی LinkedIn برای قابلیت‌های نوشتاری این بسته لازم نیست. ابزار تحلیل، مرور لینک و تولید PDF تابع امکانات میزبان است.
